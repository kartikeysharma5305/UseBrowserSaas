We receive account name/email and authentication data; Agent goals, target
sites, variables, safety/output configuration; Run inputs, events, results,
structured output, URLs and retained screenshots; schedules; usage; service
notification and webhook details; API-key metadata; and Stripe entitlement and
payment-status metadata. We do not receive or store Stripe card details.

We use this data to authenticate users, execute browser automation, send needed
content to configured AI providers, interact with user-authorized websites,
store results, enforce quotas/safety, deliver transactional notices/webhooks,
bill subscriptions, prevent abuse, support users, observe reliability, and
back up/recover the service. AI output can be inaccurate; consequential actions
require user review. Users should not submit unnecessary sensitive content.

Service providers can include Groq, Stripe, a configured email provider such as
Resend, S3-compatible storage, and selected hosting/database/backup providers.
Target websites receive normal browser requests and apply their own terms and
privacy policies. Deployment regions, transfers, contractual safeguards and
legal bases are `[TO BE REVIEWED]`.

Technical safeguards include owner scoping, encryption/hashing of credential
material, redacted logs, network restrictions, rate limits, verified backups
and recoverable deletion. No system is risk-free. Retention follows the Data
Retention Policy draft; current artifacts are retained 7/30/90 days by plan.

Users can request a bounded JSON export and initiate deletion in Settings. Some
oversized, correction, restriction or objection requests require the privacy
contact. Backups can contain data deleted after their recovery point; the
operator must keep bounded backups and reapply an external deletion journal.
