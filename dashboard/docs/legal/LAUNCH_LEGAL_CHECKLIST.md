# Launch Legal and Privacy Checklist

Technical Phase 25 completion does not resolve these launch decisions.

Required before public launch:

- [ ] Insert verified legal entity, registered address and privacy/security contacts.
- [ ] Obtain qualified review of Privacy, Terms, AUP, Cookies and retention drafts.
- [ ] Decide governing law, venue, liability, warranty and eligibility/minimum age.
- [ ] Decide refund/cancellation/tax language consistent with Stripe behavior.
- [ ] Confirm every subprocessor, contract, purpose, hosting/data region and transfer approach.
- [ ] Configure production artifact, record, log and backup retention schedules.
- [ ] Establish an external deletion-journal owner and post-restore procedure.
- [ ] Assign privacy/security incident owners and escalation contacts.
- [ ] Test production email/contact addresses and legal-document version rollout.
- [ ] Confirm no analytics/marketing code is enabled without separate consent controls.
- [ ] Run export/deletion, backup/restore, security and launch smoke drills in production-like staging.
